Building VR/AR training simulators, multiplayer worlds, and hyper-casual games for six years —
this repository is the source for my personal portfolio: a bilingual (English / فارسی),
2D-platformer-styled single-page site, built to show the work rather than talk about it.

## ✨ Highlights

- 🌐 **Bilingual by default** — full English / Persian experience with proper RTL layout
- 🕹️ **Retro platformer look** — a Mario-inspired scene (clouds, blocks, coins, a pipe) built
  entirely in CSS, no sprite sheets or external art
- ⚡ **Genuinely lightweight** — vanilla HTML/CSS/JS, no framework, no build step
- 🧩 **Content-driven** — every role, project, and skill lives in JSON, so the site updates
  without touching a line of markup
- ♿ **Built to be usable** — keyboard navigation, reduced-motion support, real focus states

## 🕹️ Selected Work

VR training simulators for industrial and medical clients, architectural AR, and a handful of
hyper-casual games — see the [live site](https://me.jollypanda.ir/bio/mohammadjavad-gholizade)
for the current lineup.
